### model и service в слое domain

---

### model — описание предметов игры

Просто **классы-описания** без логики. Отвечает на вопрос **"что существует в игре?"**

```python
# domain/model/board.py
class Board:
    cells: list  # матрица поля [[0,1,0],[2,0,1],[0,0,2]]

# domain/model/game.py
class Game:
    uuid: str    # уникальный номер игры
    board: Board # игровое поле
```

Это просто **существительные** — поле, игра. Никакой логики, только структура.

---

---

### Единая аналогия — шахматы

| Пакет | Аналогия | Пример |
|---|---|---|
| **model** | Описание фигур и доски | Ферзь, пешка, доска 8х8 |
| **service** | Правила игры и судья | Ферзь ходит на любое число клеток, мат — конец игры |

**model** — это **что** есть в игре.
**service** — это **что можно делать** в игре.

---

### Почему они в разных файлах?

Потому что **описание** и **логика** — разные вещи.

Если завтра поменяешь поле с 3х3 на 5х5 — меняешь только **model.**

Если завтра заменишь Минимакс на другой алгоритм — меняешь только **service.**

Они не мешают друг другу.
